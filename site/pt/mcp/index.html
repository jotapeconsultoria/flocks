O catálogo do Flocks, servido a agentes

Um servidor MCP com o contrato real dos 131 componentes — props, regras de uso, notas de acessibilidade, exemplos executáveis, em inglês e português. Local, por stdio, sem rede: o catálogo viaja dentro do binário.

Baixar para o Claude Desktop (.mcpb) Ver no GitHub

Por que um agente precisa disto

O Flocks é construído direto sobre widgets.dart — sem Material, sem Cupertino. Esse é o ponto do sistema, e é também o que faz um modelo errar: pedido para escrever uma tela, ele alcança os nomes de parâmetro do Material, porque é assim que Flutter se parece em todo lugar, e o resultado não compila. Este servidor entrega a lista real de props, das mesmas fontes de onde o site e o Widgetbook são gerados.

Três tools

Toda tool aceita lang (en ou pt) — o catálogo é bilíngue na fonte, campo a campo, não traduzido.

Tool Entrada Devolve
list_components category? (atom · molecule · organism) id, nome e resumo de cada componente
get_component id a ficha completa: props, quando usar e quando não, do/don't, acessibilidade, exemplos, relacionados
search_components query todo match em nomes, resumos e descrições — sem distinguir caixa nem acento

Instalação

Claude Desktop — o bundle

Baixe o flocks-mcp.mcpb e abra com o Claude Desktop — clique duplo, ou Settings → Extensions. O bundle carrega executáveis nativos para macOS (arm64/x64), Linux (x64) e Windows (x64) e escolhe o certo ao subir; nenhum SDK de Dart envolvido. Cada release publica o SHA-256 do bundle ao lado do arquivo.

Claude Code

claude mcp add flocks -- flocks_mcp

Assume o comando flocks_mcp no seu PATH — que é o que a ativação abaixo fornece.

Com o SDK do Dart

dart pub global activate flocks_mcp

Ainda não publicado no pub.dev — a publicação está a caminho. Até lá a linha acima não resolve, e o caminho de entrada é a ativação por git:

dart pub global activate --source git \
  https://github.com/jotapeconsultoria/flocks.git \
  --git-path packages/flocks_mcp
